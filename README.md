# Happy Wheels Clone

Ce dépôt contient un prototype simplifié d'un jeu de type **Happy Wheels** avec des graphismes améliorés. Le but est de servir de point de départ pour un projet complet.

## Fonctionnalités

- Ragdoll 2D basé sur la physique avec [Pymunk](https://www.pymunk.org/)
- Graphismes améliorés : sprites haute résolution, effets de particules et éclairage simple
- Code Python utilisant [Pygame](https://www.pygame.org/)

## Installation

```bash
pip install -r requirements.txt
```

## Exécution

```bash
python happy_wheels.py
```

Un fenêtre Pygame s'ouvrira et affichera le prototype du ragdoll avec quelques effets graphiques.

## Améliorations possibles

- Ajouter un éditeur de niveaux
- Implémenter davantage de personnages et d'obstacles
- Optimiser les effets de particules et l'éclairage
